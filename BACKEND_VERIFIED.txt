    v.literal("error"),

## 🏗️ Backend Architecture

### How It Works

```
1. USER UPLOADS CV
   └─→ File → Convex Storage

2. TEXT EXTRACTION (Free)
   └─→ convex/cvProcessing.ts: extractTextOnly()
       └─→ Parses PDF/DOCX/TXT
           └─→ Saves rawText to DB

3. AI PROCESSING (OpenAI GPT-5)
   └─→ convex/cvProcessing.ts: processCv()
       └─→ Gets rawText
           └─→ Sends to OpenAI (via Hercules gateway)
               └─→ Returns parsed JSON
                   └─→ Saves to DB

4. HERCULES STORES USER DATA
   └─→ User authentication (OIDC)
       └─→ User roles & permissions
           └─→ API key for OpenAI access
               └─→ NOT the CV itself (that's in Convex)

5. CONVEX STORES CV DATA
   └─→ Linked to Hercules user ID
       └─→ Each user sees only their CVs
           └─→ Files encrypted in storage
```

## 📊 Database Integration

### Where Data Goes

| Data | Stored By | Purpose |
|------|-----------|---------|
| User login | Hercules | Authentication |
| User roles | Hercules | Permissions (Admin/Recruiter/Viewer) |
| API keys | Hercules | OpenAI access |
| CV files | Convex | Document storage |
| CV data | Convex | Parsed info (name, skills, etc.) |
| CV-User link | Convex | `uploadedBy` field |

### User-Scoped Queries

```typescript
// Get only THIS user's CVs
const myCVs = await querydb("cvs")
  .filter(q => q.eq("uploadedBy", userId))
  .collect();

// Admin can see ALL CVs (no filter)
const allCVs = await querydb("cvs").collect();
```

## ❓ FAQ

**Q: Where does Hercules store the CVs?**
A: Hercules doesn't store CVs. Hercules stores: user auth, roles, API access. CVs are stored in Convex database.

**Q: Is OpenAI GPT-5 really being used?**
A: Yes! Through Hercules AI Gateway (`https://ai-gateway.hercules.app/v1`), using model `openai/gpt-5-mini`.

**Q: How do users access only their CVs?**
A: Database queries filter by `uploadedBy` field (the Hercules user ID).

**Q: What if OpenAI API fails?**
A: CVs marked as "paused". Call `resumeProcessing()` after fixing the issue.

**Q: How much does it cost?**
A: ~$0.01 per CV (OpenAI charge). Convex free tier covers most usage.
