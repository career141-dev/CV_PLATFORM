## 🚀 How to Start

### Step 1: Get API Keys (5 minutes)
1. Hercules OIDC → https://hercules.app
2. Claude API → https://console.anthropic.com
3. Convex Deploy → https://dashboard.convex.dev
4. Cloudflare Token → https://dash.cloudflare.com

### Step 2: Configure Environment (1 minute)
Fill `.env.local` with:
```
VITE_HERCULES_WEBSITE_ID=your_id
HERCULES_OIDC_AUTHORITY=https://auth.hercules.app
HERCULES_OIDC_CLIENT_ID=your_client_id
ANTHROPIC_API_KEY=sk-ant-your-key
CONVEX_DEPLOYMENT=your-deployment
```

### Step 3: Start Development (1 minute)
```bash
npm install    # Already done, Claude SDK installed
npm run dev    # Start development server
```

Your app: http://localhost:5173

## 🆘 Troubleshooting

**"Cannot find module @anthropic-ai/sdk"**
→ Run: npm install @anthropic-ai/sdk

**"ANTHROPIC_API_KEY is undefined"**
→ Check .env.local has the key, restart npm run dev

**"Hercules login not working"**
→ Verify redirect URI in Hercules dashboard matches your app URL

**"Convex connection error"**
→ Run npx convex dev in separate terminal

**"Blank page on startup"**
→ Clear browser cache, hard refresh (Ctrl+Shift+R)

See full troubleshooting in:
- QUICKSTART.md
- SETUP_GUIDE.md
- HERCULES_SETUP.md
